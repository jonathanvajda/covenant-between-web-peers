A small bridge, without a backend.

The website serves the app; public STUN helps discover network routes. Handshakes are encrypted with your passphrase, and WebRTC encrypts the live channel. Some firewalls and NAT configurations block direct connections. This app has no TURN relay; if a connection fails, try another network.

Offline support will be prepared after your first visit. Internet connections still need network access.
